Eigenes Quiz teilen

Füge dein Quiz mit + Quiz aus Datei hinzu und klicke bei der Karte auf Einreichen. QuizDesk speichert eine Kopie in deinen Downloads und öffnet ein Formular auf GitHub. Dort ziehst du die Datei hinein und schickst es ab. Sobald es freigegeben ist, erscheint es hier für alle.

Quiz hinzufügen

Fast geschafft

  1. Eine Kopie deines Quiz liegt jetzt in deinen Downloads:
  2. In deinem Browser ist das GitHub-Formular offen. Melde dich bei GitHub an, falls nötig.
  3. Zieh die Datei in das Feld Quiz-Datei und klicke auf Create.

Nach der Freigabe erscheint dein Quiz für alle unter Entdecken.
